🐍 Mini Projetos Python
💡 Descrição

Este repositório reúne uma coleção de mini projetos em Python, desenvolvidos com o objetivo de praticar lógica de programação, explorar bibliotecas populares e experimentar interfaces gráficas com frameworks como Kivy e Tkinter.

Cada projeto é independente e aborda um conceito diferente — desde aplicações simples em terminal até interfaces gráficas interativas.

🚀 Como executar

Clone o repositório

git clone https://github.com/filipeasj/mini-projetos-python.git
cd mini-projetos-python


Crie o ambiente virtual

python -m venv venv


Ative o ambiente

Windows

venv\Scripts\activate


Linux / macOS

source venv/bin/activate


Instale as dependências

pip install -r requirements.txt


Execute o projeto desejado

python calculadora.py


(ou qualquer outro arquivo Python do repositório)

🧠 Objetivo

Este repositório serve como um espaço de aprendizado contínuo, permitindo:

Praticar conceitos de programação estruturada e POO;

Explorar bibliotecas Python (Tkinter, Kivy, Random, Time, etc.);

Criar pequenos programas úteis e divertidos;

Construir um portfólio prático de código.

🧰 Tecnologias utilizadas

Python 3.11+

Kivy (interfaces gráficas modernas)

Tkinter (interfaces simples e nativas)

Virtualenv (venv)
